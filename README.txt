QR通信 v0.33 試作版

v0.32実機試験を反映。

変更点
- Payload選択に 768B / 1024B を追加
  既存: 64 / 128 / 256 / 512B
- 新規端末の自動送信間隔初期値を0.1秒へ変更
  既存端末では保存済み設定を優先
- 受信カメラ表示を大きな正方形フレームへ変更
- jsQRへ渡す解析領域もカメラ映像中央の正方形へ限定
  QRコード形状と解析領域を一致させる
  周辺の不要領域を解析しないため処理負荷低減も期待
- 自動送信、大きなブロック番号、−10/←/→、終了、ズーム抑止は継続

Payload評価の目安
- 512B: 現在の実績値
- 768B: 中間評価
- 1024B: 高速化候補

0.1秒/ブロックで1024Bが安定すれば、理論Payload速度は約10KB/s。
