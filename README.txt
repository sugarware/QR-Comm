QR通信 v0.44
- メイン画面のボタンを「送信 / 表示」「受信 / 読込」に変更
- メイン画面下部に本アプリURL (https://sugarware.github.io/QR-Comm/) のQRコードを表示
- 通常QR表示時は、QR通信用の送信説明文を非表示
- 通常QR読込完了後、認識したQRコード画像をカメラ領域に静止表示
- 通常QR読込に1次元BARコード（EAN/UPC/Code 128/39/93/ITF/Codabar/RSS系）認識を追加
- QR通信のバイナリQR受信は従来どおりjsQRを使用し、BARコード認識とは分離
- v0.43の通信仕様、画面デザイン、診断機能を継承
