QR通信 v0.2 試作版

v0.1実機評価を反映。

変更点
- 通常QRの日本語をUTF-8 Byte modeで生成
- 受信開始時に前回の受信状態と結果表示を完全初期化
- カメラ再開直後400msは読み取りを開始しない
- videoを停止・srcObject解除してから新しいカメラストリームを開始
- 同一デコード結果の短時間重複処理を抑制
- 標準Payloadを128Bから512Bへ変更
- 64/128/256/512Bの選択は継続
- QR通信のブロック切替は手動←/→方式を維持

注意
- 既にブロックサイズがlocalStorageへ保存済みの場合は、その設定値が優先されます。
  512Bを試す場合は設定画面で512Bを選んでください。
- QR生成/読取ライブラリはCDN利用。
- カメラ利用にはHTTPSまたはlocalhostが必要です。
