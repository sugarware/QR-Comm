QR通信 v0.31 試作版

v0.3実機試験の修正版。

修正・変更
- 自動ボタンが反応しなかった不具合を修正
  原因: イベント登録がIIFEの外に出ており、関数を参照できなかった。
- 自動送信間隔を1.0秒から0.4秒へ短縮
  約2.5ブロック/秒。
- 復旧用［−10］ボタンを追加
- ［←］は1ブロック戻る、［→］は1ブロック進む
- 手動操作すると自動送信を停止
- 送信側・受信側のブロック番号を大きく表示
- ズーム抑止は継続

読み損ない時の想定操作
例: 受信側が「受信済み 36 / 99」で停止
1. 送信側で⏸停止
2. ［−10］や［←］で送信ブロックを37付近まで戻す
3. 必要なら［→］で37へ合わせる
4. ▶自動で再開

0.4秒は実機評価用の暫定値。
