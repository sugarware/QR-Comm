QR通信 v0.3 試作版

v0.2の実機試験結果を反映。

主な変更
- 送信側・受信側のブロック番号を大きく表示
- QR通信送信に1秒間隔の自動送信を追加
- ▶ 自動 / ⏸ 停止 で開始・停止・再開
- ← / → は大型化し、手動で戻る・進む操作に使用
- 手動操作時は自動送信を停止
- 最終ブロックで自動停止
- ダブルタップ/ピンチによる画面ズームを抑止
- touch-action: manipulation を適用
- v0.2のUTF-8、受信再開対策、512B標準Payloadは継続

想定する復旧操作
1. 受信側の「受信済み N / Total」が止まる
2. 送信側で⏸停止
3. 送信側を N+1 ブロックまで←で戻す
4. ▶再開

音声ACK/NAKは引き続き未実装。
現段階では「通常は自動送信、読み損ない時だけ人間が介入」の方式を評価する。
